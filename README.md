A one-sentence startup pitch for make.fun's "Ridiculous at First Glance, Real by the Second" bounty. The program writes a single sentence (200 characters at most) to the output file. The pitch: tiny funerals for dead houseplants, sold for $29 a time to the serial plant-killers who keep producing the customers — absurd for half a second, then an obviously repeatable business.

## Run it

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt` (override the directory with the `MAKEFUN_OUTPUT_DIR` environment variable).
